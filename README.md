
# SuperMarket Sales Dashboard – Power BI

## Project Overview
This project focuses on analyzing supermarket sales data and presenting business insights through an interactive Power BI dashboard.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Project Objectives
- Analyze supermarket sales performance.
- Monitor total revenue and transactions.
- Analyze returns and sales targets.
- Identify business trends and performance.
- Present insights through interactive dashboards.

- Data Cleaning
- Data Modeling
- DAX Measures Creation
- Dashboard Development
- Business Performance Analysis
